Type Akan (Twi) text, hear it spoken by our fine-tuned model -- no external TTS API.

- Model: [Lhue-Lhue/akan-tts-mms-vits](https://huggingface.co/Lhue-Lhue/akan-tts-mms-vits), fine-tuned from
  `facebook/mms-tts-aka` (Meta MMS, CC-BY-NC-4.0, non-commercial use only).
- Code, data preparation, evaluation and docs: [YCienne/TTS](https://github.com/YCienne/TTS).
- Built for the University of Ghana HCI Lab TTS task.
